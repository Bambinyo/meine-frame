# Meine FRAME

Deine eigene Kunstgalerie für den Samsung-Fernseher „The Frame“ – bequem vom Mac und vom iPhone aus.

**So geht’s:** [MeineFRAME.zip](https://github.com/Bambinyo/meine-frame/raw/main/MeineFRAME.zip) herunterladen, dann im Terminal `bash ~/Downloads/MeineFRAME/installieren.sh` einfügen. Die Anleitung liegt im Paket. Danach hält sich Meine FRAME ganz von allein auf dem neuesten Stand.

*Ma Frame, version allemande. Le paquet d'installation et les fichiers de mise à jour automatique (maj.zip, version.json) sont à la racine du dépôt.*

Kein offizielles Samsung-Produkt.
