# Meine FRAME

Kunst für den Samsung-Fernseher „The Frame“, gesteuert vom Mac.
Installation: [MeineFRAME.zip](https://github.com/Bambinyo/meine-frame/raw/main/MeineFRAME.zip) herunterladen, öffnen, dann im Terminal: `bash ~/Downloads/MeineFRAME/installieren.sh`. Danach aktualisiert sich die App von selbst.

*Ma Frame, version allemande. Le paquet d'installation et les fichiers de mise à jour automatique (maj.zip, version.json) sont à la racine du dépôt.*

Nicht mit Samsung verbunden.
